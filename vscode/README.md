# SovietWave

Tema que mistura a estética Synthwave com as cores do comunismo.

## Temas Inclusos

- **SovietWave**: A paleta original vibrante.
- **SovietWave - Zhukov**: Uma variação com tons vermelhos mais escuros.

## Como instalar

1. Abra o painel de extensões no VS Code (ou IDE compatível).
2. Procure por `SovietWave`.
3. Clique em Instalar.

## Como usar

Vá em **File > Preferences > Color Theme** e selecione `SovietWave` ou `SovietWave - Zhukov`.
