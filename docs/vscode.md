# Instalação: Visual Studio Code

O tema SovietWave está disponível como uma extensão oficial para o Visual Studio Code, alterando toda a interface, a coloração de código e os componentes visuais.

## 📥 Método 1: Via Marketplace Oficial (Recomendado)

*Nota: O tema está atualmente em processo de publicação. Em breve você poderá instalá-lo diretamente pelo Marketplace usando as instruções abaixo.*

1. Abra o VS Code.
2. Pressione `Ctrl + Shift + X` (Windows/Linux) ou `Cmd + Shift + X` (Mac) para abrir a aba de **Extensões**.
3. Pesquise por **"SovietWave"**.
4. Clique no botão **Install**.
5. Em seguida, acesse `Preferences: Color Theme` (atalho `Cmd/Ctrl + K`, depois `Cmd/Ctrl + T`) e selecione **SovietWave** ou **SovietWave Zhukov**.

## 🛠️ Método 2: Instalação Manual via arquivo `.vsix`

Caso você tenha baixado o pacote de lançamento ou clonado o repositório, você pode instalar o tema manualmente usando o arquivo `.vsix` compilado.

1. Baixe o arquivo `sovietwave-X.X.X.vsix` da aba de [Releases](https://github.com/victorcrbt/sovietwave/releases).
2. Abra o VS Code.
3. Pressione `Cmd/Ctrl + Shift + P` para abrir a **Command Palette**.
4. Digite e selecione: **`Extensions: Install from VSIX...`**.
5. Navegue até o arquivo `.vsix` que você acabou de baixar e confirme.
6. Pronto! O tema será instalado na hora. Selecione a variante desejada no seletor de temas e aproveite o novo visual.
