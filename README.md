# SovietWave Theme 🌊

Bem-vindo ao projeto **SovietWave**! Este repositório contém um tema escuro retrofuturista, inspirado no synthwave, com tons de vermelho profundo, cinzas elegantes e acentos cianos brilhantes, trazendo a nostalgia do retrofuturismo soviético para o seu ambiente de desenvolvimento.

## 📦 Ambientes Suportados

Atualmente fornecemos temas nativos adaptados para os seguintes editores e plataformas:

- **[Visual Studio Code](docs/vscode.md)**
- **[Codex Desktop](docs/codex.md)**

## 🎨 Variantes

O tema vem em duas vertentes distintas:
- **SovietWave (Base)**: A estética padrão, equilibrando alto contraste com tons atmosféricos.
- **SovietWave Zhukov**: Uma variante ainda mais ousada, com destaques vermelhos predominantes para quem prefere uma presença visual marcante.
